# Мій день — Android/Kivy

У проєкті є `main.py`, `buildozer.spec` і GitHub Actions workflow для збірки APK у хмарі.

## Як зібрати з телефона
1. Створи репозиторій на GitHub.
2. Завантаж усі файли цього проєкту в корінь репозиторію, зберігши `.github/workflows/build-apk.yml`.
3. Відкрий вкладку **Actions** і запусти **Build My Day APK** через **Run workflow** (або зроби push у `main`).
4. Після успішної збірки відкрий запуск workflow та завантаж artifact `miy-den-apk`.
5. Розпакуй ZIP і відкрий APK на телефоні. Android може попросити дозволити встановлення з браузера/файлового менеджера.

Збірка виконується у хмарі; перший запуск може тривати кілька хвилин. Якщо build завершиться помилкою, переглянь лог кроку збірки.
